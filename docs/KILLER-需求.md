- **2026-11-11**：从 Python 重写为 Go，且核心功能从「基金筛选+净值监控」改为「股票大盘监控」，原因是 [用户要求 Go 重写并变更主功能]

- **2026-11-11**：纳指100成分表用 yfiua.github.io（月度更新）而非东财/新浪，原因是 [东财无纳指成分接口、新浪无，海外源经实测 GitHub Pages 国内可达且数据齐全]
