# 免费金融数据源调研报告

> 调研时间：2025-06-17 | 适用场景：公募基金数据采集

---

## 一、调研范围

本次调研覆盖以下维度的免费数据接口：
- 公募基金净值（单位净值、累计净值）
- 基金实时估值
- 基金持仓明细
- 基金经理信息
- A股实时行情（辅助）

---

## 二、数据源详解

### 2.1 AkShare（⭐ 首选推荐）

| 属性 | 说明 |
|------|------|
| 官网 | https://akshare.akfamily.xyz |
| GitHub | https://github.com/akfamily/akshare |
| 费用 | **完全免费**，无需注册 |
| 协议 | MIT 开源 |
| 安装 | `pip install akshare` |
| 数据来源 | 东方财富、天天基金网、新浪财经等公开网页 |
| 更新频率 | 随交易日更新，盘中支持实时估值 |

#### 基金相关核心接口

| 接口函数 | 说明 |
|----------|------|
| `fund_em_open_fund_daily()` | 全部开放式基金日度数据（代码、简称、净值、累计净值、日增长率） |
| `fund_em_open_fund_info(fund, indicator)` | 单只基金历史净值走势（单位净值/累计净值/实时估值） |
| `fund_em_real_time()` | 基金实时估值（盘中） |
| `fund_em_portfolio_hold(fund, date)` | 基金持仓明细（前十大重仓股） |
| `fund_em_manager()` | 基金经理信息 |
| `fund_em_company()` | 基金公司列表 |
| `fund_em_aum_hist()` | 基金规模变动历史 |

#### 优缺点

- ✅ 接口最全，覆盖90%以上的基金数据需求
- ✅ 完全免费开源，社区活跃
- ✅ Pandas DataFrame 直接输出，接入成本极低
- ❌ 底层爬虫，目标网站结构变更时可能短期失效
- ❌ 无商业化 SLA 保障，高频调用可能被反爬
- ❌ 部分接口速度较慢（同步 HTTP 爬取）

---

### 2.2 Tushare Pro（⭐ 备用推荐）

| 属性 | 说明 |
|------|------|
| 官网 | https://tushare.pro |
| 费用 | **基础功能免费**（200次/天），高级接口需积分 |
| 安装 | `pip install tushare` |
| 数据来源 | 自有数据源 + 公开数据 |

#### 基金相关接口

| 接口 | 所需积分 | 说明 |
|------|---------|------|
| `fund_daily` | 免费 | 基金日线行情 |
| `fund_nav` | 200 | 基金净值（单位/累计） |
| `fund_portfolio` | 200 | 基金持仓 |
| `fund_basic` | 免费 | 基金基本信息 |
| `fund_manager` | 免费 | 基金经理 |

#### 优缺点

- ✅ 数据标准化程度高，字段规范
- ✅ 官方维护，稳定性优于爬虫方案
- ✅ 支持分钟级数据
- ❌ 免费额度有限（每日200次）
- ❌ 高级接口需要积分（可通过社区贡献获取）
- ❌ 需注册获取 API Token

### 2.3 Baostock（历史数据补充）

| 属性 | 说明 |
|------|------|
| 官网 | http://baostock.com |
| 费用 | **完全免费**，无需注册 |
| 安装 | `pip install baostock` |

#### 适用场景

- 历史K线数据回测
- 前复权/后复权因子计算
- 不支持实时数据

#### 优缺点

- ✅ 完全免费，无需注册
- ✅ 5年以上的历史数据覆盖
- ❌ 仅支持股票/指数，基金数据有限
- ❌ 无实时数据

---

### 2.4 天天基金网直连（AkShare 底层源）

天天基金网（fund.eastmoney.com）是 AkShare 基金接口的底层数据来源。

#### 关键 URL 模式

```
# 基金列表
http://fund.eastmoney.com/js/fundcode_search.js

# 基金净值历史
http://fund.eastmoney.com/f10/F10DataApi.aspx?type=lsjz&code={code}&page={page}&sdate={start}&edate={end}&per={per}

# 基金实时估值
http://fundgz.1234567.com.cn/js/{code}.js
```

#### 优缺点

- ✅ 数据源头，实时性最好
- ❌ 需自行解析 HTML/JS
- ❌ 可能触发反爬机制
- ❌ 无官方 API 文档

### 决策矩阵

| 场景 | 方案 | 理由 |
|------|------|------|
| 日常基金数据拉取 | AkShare | 免费、接口全、DataFrame 输出 |
| AkShare 接口失效 | 天天基金网直连 | 同一数据源，回退到原始抓取 |
| 高级财务分析 | Tushare Pro | 数据更规范、字段更全 |
| 历史回测 | Baostock | 复权因子完整，历史久 |
| 生产环境 | 考虑 Wind/Choice 商业数据 | 有 SLA 和法律合规保障 |
